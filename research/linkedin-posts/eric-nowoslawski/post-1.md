# Favorite API Tools for Cold Outreach Automation

**Author:** Eric Nowoslawski  
**Date:** 2025-04  
**Profile:** https://linkedin.com/in/outboundphd  

---

An updated list of my favorite API tools and what we use them for. As usual, never any affiliate links.

1. **Clay / Claygent**
   - Job / hiring signals
   - Counting roles in a department
   - Orchestrating workflows
   - Calling other tools + running AI with cached inputs

2. **Prospeo / BlitzAPI**
   - Main company + contact finders
   - LinkedIn-based data + enrichment
   - Org structure + role lookups
   - Also found MailTester.Ninja for email validation

3. **OpenWeb Ninja**
   - Google search scraping
   - Company news, blogs, competitors
   - "If I'd Google it manually, automate it"

4. **Rapid API / Apify**
   - Marketplaces for Data Scrapers
   - LinkedIn profile + post scraping
   - Google reviews + search endpoints
   - Structured API-based data pulls

5. **Parallel Web Systems**
   - Deep research when data isn't structured
   - Pricing, hiring, product info
   - Fallback when nothing else works

6. **Scrape Creators** — Social media scraping (IG, TikTok, FB)

7. **Disco** — Like Ocean.io for lookalike targeting

8. **BuiltWith / Store Leads**
   - Finding companies using specific tech
   - Shopify / ecommerce list building

9. **ZenRows / Spider.Cloud**
   - Scraping websites directly
   - Getting around bot protection
   - Extracting products + page content

10. **Browser Use** — Automated browser scraping that needs clicking around

**Key insight:** Using Claude/Codex task agents to scrape automatically — included in $200/month bill anyway.
