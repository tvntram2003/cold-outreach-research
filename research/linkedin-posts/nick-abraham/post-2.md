# Claude Code Runs Our Entire Outbound System at Leadbird — 11 Lessons

**Author:** Nick Abraham  
**Date:** 2025-04  
**Profile:** https://linkedin.com/in/nick-abraham  

---

Claude Code now runs our entire outbound system at Leadbird.
Here's everything learned about running outbound the right way:

1. Claude won't fix a bad offer, bad deliverability, or lack of 
   product-market fit. Fundamentals must be in place first.

2. True value of Claude at scale = **speed of launch**. For an agency 
   running hundreds of clients, getting campaigns out faster compounds 
   massively.

3. Build a separate Claude skill for every part of the campaign process:
   offer design, copywriting, list building, etc.

4. Connect all skills into a **single orchestrator** that runs through 
   them in sequence — whole campaign flows from one step to the next.

5. Build a checklist into each skill so Claude checks whether output 
   hits all fundamentals when running evals.

6. AI is better than before at suggesting offers, but still can't 
   understand nuances of your business. **Human in the loop required.**

7. Your inputs determine your outputs. Vague ICP description = 
   generic output.

8. Writing good inputs is a skill you develop through reps over time.

9. When choosing a reference website for Discolike, pick a company 
   that's a 100% perfect match for ICP.

10. Always have a **human checkpoint** after Claude generates copy — 
    catch mistakes that leave performance on the table.

11. Benchmark every campaign against monthly performance. If a campaign 
    is doing 30-40% worse than target, use orchestrator to spin up 
    a replacement.

**Key insight:** Claude Code is an operations multiplier for agencies —
not a replacement for fundamentals or human judgment.
